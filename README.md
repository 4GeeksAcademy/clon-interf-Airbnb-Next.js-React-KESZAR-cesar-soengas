# interfaz de Airbnb con Next.js y React

**clon-interf-Airbnb-Next.js-React-KESZAR-cesar-soengas**

Validar la arquitectura de componentes clonando una interfaz de producción bien conocida: Airbnb. De esta forma, el equipo aprende qué componentes son necesarios, qué datos necesita cada uno y cómo se conectan entre las distintas vistas.

Implementar **tres vistas** de la experiencia de Airbnb en Next.js usando componentes de React:

1. La **página de inicio (Home)**.
2. La **página de catálogo (resultados de búsqueda)**.
3. La **vista de detalle de una habitación**.
